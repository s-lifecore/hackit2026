# ファイルオート振り分け（仮）

## 概要

配布資料を自動で振り分けられるようにするデスクトップアプリです。

## 開発背景（解決したい課題・きっかけ）

自分の雑さをツールで緩和させたい。

ダウンロードフォルダに配布資料が溜まり続け、整理されないまま放置されてしまう課題を解決します。

## 想定ユーザー

- 配られたものをまとめられない人
- ダウンロードしたファイルをダウンロードフォルダに入れっぱなしにしがちな人

## 技術スタック

| 項目 | 技術 | 用途 |
| --- | --- | --- |
| アプリ基盤 | **Electron** | デスクトップアプリ化 |
| UI | **HTML + CSS + JavaScript（Vanilla JS）** | 画面作成 |
| デザイン | **CSS**（必要ならBootstrap） | レイアウト・装飾 |
| アニメーション | **CSS Animation / Web Animations API** | ファイル移動演出 |
| ファイル監視 | **chokidar** | ダウンロードフォルダの監視 |
| ファイル操作 | **Node.js (`fs/promises`)** | ファイルの移動・コピー・削除 |
| データベース | **SQLite** | ルール・履歴・設定の保存 |
| SQLiteライブラリ | **better-sqlite3** | SQLite操作 |
| IPC通信 | **Electron IPC (`ipcMain` / `ipcRenderer`)** | UIとバックエンドの通信 |
| 配布 | **electron-builder** | Windows向けインストーラー作成 |

## 機能

### 必要そうなもの・あったら使いたいもの

- ダウンロードしたファイルを自動でフォルダに振り分ける（必須）
- 新しいファイルが追加されたら自動で検知する
- ファイルの移動時にアニメーションを組み込む
- アニメーションを選べるようにする
- ファイルの提出日（課題の期限など）ごとにまとめる
- おすすめ振り分け（過去に似たファイルがダウンロードされていた場合、振り分け先を提案）

### 優先順位

1. ダウンロードしたらフォルダに入れる
2. アニメーション
3. 提出日ごとの振り分け
4. 新しいファイルが追加されたら自動で検知する
5. アニメーションを選べる
6. おすすめ振り分け
