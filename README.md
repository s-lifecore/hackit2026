# ファイフリ（filefly）

### ダウンロードフォルダの中身を、名前を見ただけで科目ごとに片付けてくれるアプリ

**作品名：** ファイフリ（filefly）
**由来：** 「ファイル」を「振り」分ける、そのままの名前。ダウンロードフォルダに散らかった課題・配布資料が、勝手に授業フォルダへ飛んでいく（fly）様子から。

**制作の背景**

- 授業ごとの資料がダウンロードフォルダに全部混ざって溜まり、あとで探すのが大変
- 手作業でのフォルダ分けは毎回同じ作業なのに続かない
- ネイティブモジュール（SQLite等）に依存するとチームメンバーの環境によって `npm install` が失敗する、という事故を避けたい

**技術スタック：**

- **本体：** Electron（Node.js のメインプロセス＋Chromiumのレンダラー）
- **永続化：** JSON ファイル（ネイティブ依存ゼロ。理由は [`docs/仕様書.md`](docs/仕様書.md#11-sqlite-ではなく-json-ファイル) 参照）
- **振り分けロジック：** ルールベースの自作エンジン（機械学習・外部通信なし）
- **対応ファイル：** PDF / Word / PowerPoint / Excel / テキスト系（中身も読む）、それ以外はファイル名のみで判定
- **配布形式：** electron-builder（NSIS インストーラ／ポータブル exe）
- **CI：** GitHub Actions（ESLint / テスト自動実行）

**ターゲット：** 授業資料の整理に困っている大学生（自分たち含む）

## 機能一覧

### 実装済みの機能

- **初回セットアップ**：科目の数・科目名を入力すると、親フォルダの下に科目フォルダを自動作成
- **自動振り分け**：PC起動時に1回、ダウンロードフォルダをスキャンして判定できたファイルを科目フォルダへ移動
- **手動振り分け（ドラッグ&ドロップ）**：判定できなかったファイルをフォルダへドラッグすると移動し、同じ命名パターンを学習する
- **ルールベースの判定エンジン**：ファイル名の一致・資料の先頭（表紙）の一致・過去に教えた命名規則の3系統の証拠を組み合わせて判定し、根拠が無いものは動かさない（誤配置対策）
- **エクスプローラーとのリアルタイム同期**：`fs.watch` によるフォルダ監視で、エクスプローラー側の追加・削除・移動を画面に反映
- **移動履歴**：振り分け結果を履歴欄で確認できる
- **キーワード指定**：科目ごとに判定用のキーワードを追加できる（略称で配布される資料向け）
- **タスクトレイ常駐・自動起動**：PC起動時にウィンドウを出さず1回だけスキャンし、常駐して待機
- **初回チュートリアル**：使い方をアプリ内で確認できる

### 今後の展望

- macOS / Linux 対応
- 判定精度のさらなる改善（学習データの可視化など）

## 動かす

```bash
cd filefly
npm install
npm start
```

## ダウンロード（ビルド不要）

自分でビルドしなくても、[GitHub Releases](../../releases/latest) から実行ファイルを直接ダウンロードできます。

| ファイル | 内容 |
|---|---|
| `FileFly Setup 1.0.0.exe` | インストーラ。ダブルクリックしてインストール |
| `FileFly-portable-1.0.0.exe` | インストール不要。ダブルクリックで起動 |
| `scripts/起動.bat` | ポータブル版exeと同じフォルダに置いて実行すると、そのexeを探して起動する |
| `scripts/セットアップ.bat` | 開発者向け。ソースコードから `npm install` → `npm start` まで自動で行う |

## exe を作る

**Windows の PC で実行してください。**

```bash
npm run dist
```

`dist/` に次の2つができます。

| ファイル | 内容 |
|---|---|
| `ファイフリ Setup 1.0.0.exe` | インストーラ（スタートメニュー・デスクトップにショートカット） |
| `ファイフリ-portable-1.0.0.exe` | インストール不要。ダブルクリックで起動 |

ポータブル版だけでよければ `npm run dist:portable`。

## 使い方

1. 初回起動 → 科目の数を選び、科目名を入力 → 「フォルダを作る」で親フォルダを選ぶ
   - 入力した科目名がそのままフォルダ名になり、振り分けのルールにもなります
2. スキャンするフォルダは既定で **OS のダウンロードフォルダ**。画面上部のパスボタンから変更できます
3. **PC を起動すると自動で1回スキャン**します（タスクトレイに常駐）
4. 判定できなかったファイルは **ダウンロードフォルダに残ります**。フォルダへドラッグして教えると、次回から自動で振り分けられます
5. 移動した結果は履歴欄で確認できます

自動起動のオン/オフはタスクトレイのアイコンを右クリック →「PC起動時に自動で実行する」。

## テスト

```bash
npm test
```

`html.test.js`（画面のHTMLが壊れていないかの検査）→ `classifier.test.js`（振り分けロジック）→ `precision.test.js`（判定精度）→ `scan.test.js`（スキャン〜移動〜学習〜復旧の通し）→ `subjects.test.js`（科目の削除・実在チェック）→ `sync.test.js`（同期）→ `setup-cancel.test.js`（セットアップ）→ `watcher.test.js`（フォルダ監視）の順に実行されます。各テストの内容は [`docs/仕様書.md`](docs/仕様書.md#5-テスト) を参照してください。

`npm run lint` で ESLint によるコードチェックも行えます。GitHub Actions で push / PR のたびに両方が自動実行されます。
