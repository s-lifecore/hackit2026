# ファイフリ（filefly）

ダウンロードフォルダに溜まった授業資料を、科目フォルダへ自動で振り分ける Windows デスクトップアプリ。

**ネイティブモジュールを一切使っていません。** `npm install` は Visual Studio Build Tools 無しで必ず通ります。

設計判断の理由・振り分けロジックの詳細・対応ファイル形式・ディレクトリ構成・テスト内容などは [`docs/仕様書.md`](docs/仕様書.md) を参照してください。

---

## 1. 動かす

```bash
cd filefly
npm install
npm start
```

## 2. exe を作る

**Windows の PC で実行してください。**

```bash
npm run dist
```

`dist/` に次の2つができます。

| ファイル | 内容 |
|---|---|
| `ファイフリ Setup 1.0.0.exe` | インストーラ（スタートメニュー・デスクトップにショートカット） |
| `ファイフリ-portable-1.0.0.exe` | インストール不要。ダブルクリックで起動 |

ポータブル版だけでよければ `npm run dist:portable`。

---

## 3. 使い方

1. 初回起動 → 科目の数を選び、科目名を入力 → 「フォルダを作る」で親フォルダを選ぶ
   - 入力した科目名がそのままフォルダ名になり、振り分けのルールにもなります
2. スキャンするフォルダは既定で **OS のダウンロードフォルダ**。画面上部のパスボタンから変更できます
3. **PC を起動すると自動で1回スキャン**します（タスクトレイに常駐）
4. 判定できなかったファイルは **ダウンロードフォルダに残ります**。フォルダへドラッグして教えると、次回から自動で振り分けられます
5. 「元に戻す」で直前の移動を取り消せます（学習も巻き戻ります）

自動起動のオン/オフはタスクトレイのアイコンを右クリック →「PC起動時に自動で実行する」。

---

## 4. テスト

```bash
npm test
```

`classifier.test.js`（振り分けロジック）→ `scan.test.js`（スキャン〜移動〜学習〜復旧の通し）→ `subjects.test.js`（科目の削除・実在チェック）の順に実行されます。各テストの内容は [`docs/仕様書.md`](docs/仕様書.md#5-テスト) を参照してください。
